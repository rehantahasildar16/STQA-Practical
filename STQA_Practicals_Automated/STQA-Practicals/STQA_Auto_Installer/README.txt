STQA PRACTICAL AUTOMATION - REQUIREMENTS

1. Install a supported Python version and ensure it is added to PATH.
2. Open this folder and double-click install_requirements.bat.
3. Wait for the package installation to finish.

Packages: Selenium, openpyxl, pytest, pytest-html, Locust.
Python built-in modules do not need installation.

This does not install browsers, Java, Jenkins, or a Selenium Grid server.
Practical 4 and 18 need an active Selenium Grid server. Practical 5, 9, 10
need internet access. Practical 17 demonstrates the Selenium script; actual
Jenkins setup/service configuration remains a separate manual step.
