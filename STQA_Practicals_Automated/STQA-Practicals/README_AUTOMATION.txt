STQA PRACTICAL AUTOMATION MENU
===============================

START: Double-click RUN_STQA.bat

Select a practical number from the menu. Practical 3 opens the supplied CSV
worksheet. Practical 7 reads Students_data.csv; option 2 writes a separate
Students_data_updated.csv and does not overwrite the original.

IMPORTANT REQUIREMENTS
- Python must already be installed and available in PATH.
- Install packages using STQA_Auto_Installer\install_requirements.bat.
- Selenium practicals require a compatible installed browser (Chrome is used
  by most scripts) and internet where the practical uses a public website.
- Practical 4 and Cross-browser Practical 18 require a running Selenium Grid.
  Enter its reachable URL when prompted.
- Locust Practical 19 requires a reachable target URL; run only against a site
  you own or have permission to load test.
- Practical 17 runs the local Selenium demo script; Jenkins itself must be
  installed/configured separately to demonstrate scheduled/automated builds.
- Practical 1 and 2 were not present in the uploaded ZIP, so they are not in
  the menu.

The launcher standardizes paths and provides one menu, but cannot guarantee
all practicals run on every PC: browser versions, network, remote Grid,
website availability, firewall, and OS/Python compatibility matter.
Test on a supported Windows PC with internet and a browser installed.
